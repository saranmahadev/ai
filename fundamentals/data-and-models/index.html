Data and Models

AI Fundamentals1 min read

Before an AI system can decide anything, it has to perceive, and for most modern systems perceiving means turning the world into data. This district explains what data is, how it is described with features and labels, what a model does with it, the difference between training and inference, and the main types of tasks.

Topics on this stretch of the road:

  • Data as Raw Material: the forms data takes, and why they all become numbers.
  • Features and Labels: what a model looks at, and what it is asked to predict.
  • A Model Is a Function: inputs in, predictions out, with adjustable numbers in between.
  • Training vs Inference: learning the numbers, then using them.
  • Types of Tasks: classify, predict a number, group, generate, or choose actions.

Data as Raw Material

Data is recorded information about the world: measurements, text, images, sound, clicks, transactions.

Features and Labels

Features are the measurable facts a model looks at, and a label is the answer it is asked to predict.

A Model Is a Function

A model is a function: give it inputs and it returns a prediction.

Training vs Inference

Training is when a model's parameters are adjusted using examples. Inference is when the finished, frozen model is used to make predictions on new inputs.

Types of Tasks

Most AI problems fall into a few kinds: classify (pick a category), predict a number, group similar things without labels, generate new content, or choose actions over time.
