Fundamentals

AI Fundamentals1 min read

AI Fundamentals answers the questions everything else builds on: what counts as AI, what an intelligent system is made of, how it perceives, decides and acts, and how we judge whether it works. There is no maths here, only ideas, small examples and simulations you can play with.

By the end you will be able to take any AI system, from a thermostat to a chatbot, and describe it as a goal, some data, a model, a decision loop and a way to judge it. The later subjects, from Math to Agents, fill in each piece.

Topics

  1. What Is AI: what the word covers, how AI, machine learning and deep learning nest, and why we learn rules from data instead of writing them.
  2. The Agent: the unit every AI system is built around, and the perceive → decide → act loop.
  3. Data and Models: what data is, what a model is, and the difference between training and using one.
  4. Classic AI: search, heuristics, logic, planning and expert systems, the methods AI used before learning took over.
  5. Judging AI: how to measure a system, whether it generalises, where it fails, and how the whole picture fits together.

Next come Math, the language every model is written in, and then Machine Learning.

What Is AI

This section answers the first question: what is AI? The honest answer is that the word covers a family of ideas, and which systems count depends on how you define it.

The Agent

Almost every AI system, however different it looks, has the same shape: it is an agent inside an environment. It senses what is happening, decides what to do to reach a goal, and acts, over and over.

Data and Models

Before an AI system can decide anything, it has to perceive, and for most modern systems perceiving means turning the world into data.

Classic AI

Before machine learning took over, AI meant searching, reasoning and planning with hand-built knowledge.
