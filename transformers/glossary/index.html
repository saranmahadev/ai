Glossary

Transformers Glossary

95 terms from Transformers.

[CLS] token
a special, learned token prepended to a sequence, whose final output summarizes the whole input for classification. from Vision Transformers
Absolute position
a token's fixed index within the sequence (0, 1, 2, …), as opposed to its position relative to another token. from Learned Positional Embeddings
Active parameters
the subset of a model's total parameters actually used to process a given input — can be far smaller than the total in an MoE model. from Mixture-of-Experts Transformer Blocks
All-reduce
combining (here, summing) partial results computed on different devices into one final result. from Splitting a Transformer Across Devices
Associativity
the property that matrix multiplication gives the same result regardless of grouping, which the linear-order trick relies on. from Linear Attention Approximations
Attention-pair cost
the number of query-key comparisons an attention computation makes, used here as a simple proxy for compute cost. from Choosing an Architecture Family for a Task
Autoregressive
generating output one step at a time, where each new output becomes part of the input for the next step. from Decoder-Only Architectures
Autoregressive generation
producing a sequence one token at a time, each depending on everything generated before it. from KV-Caching for Autoregressive Inference
Batching
grouping multiple inference requests together to process in a single pass, amortizing fixed per-batch overhead. from Inference Serving Trade-offs
Bidirectional attention
attention that allows looking both backward and forward in a sequence, as opposed to causal (backward-only) attention. from Encoder-Only Architectures
Causal mask
blocks every query from attending to positions later than itself in the sequence. from Attention Masks: Padding and Causal Masking
Causal masking
restricting attention so a position can only see itself and earlier positions, never later ones. from Decoder-Only Architectures
Chunk
the portion of a split weight matrix stored and computed on one device. from Splitting a Transformer Across Devices
Co-occurrence score
WordPiece's merge criterion, a pair's frequency divided by the product of its two pieces' individual frequencies. from WordPiece and SentencePiece
Combined sequence
a single sequence built by concatenating vectors from more than one modality. from Multimodal Transformers as an Architecture Pattern
Correction factor
the rescaling term that keeps a running softmax computation consistent as new blocks of data arrive. from IO-Aware Attention Computation
Cross-attention
attention where queries come from one sequence and keys/values come from a separately computed sequence. from Encoder-Decoder Architectures as a Pattern
Cross-modal attention
attention weights spreading across positions from different modalities within one computation. from Multimodal Transformers as an Architecture Pattern
d_ff
the width of the feed-forward sublayer's hidden layer, conventionally 4 times d_model. from The Feed-Forward Sublayer
the feed-forward sublayer's hidden width, conventionally 4 times d_model. from Counting a Transformer's Parameters and FLOPs
d_model
the width of every vector flowing through a transformer's layers. from Token Embeddings and Embedding Scaling
Decoder-only
a transformer architecture using causal masking throughout, suited to generating text one token at a time. from Decoder-Only Architectures
Direction-preserving
a transformation that outputs a positive scalar multiple of its input, leaving relative proportions and signs unchanged. from RMSNorm vs LayerNorm
Effective receptive field
how far information can travel across multiple stacked layers, even when each individual layer's range is limited. from Sparse and Local (Windowed) Attention
Elementwise multiplication (⊙)
multiplying two vectors position by position, combining the gate and up projections. from Modern Feed-Forward Variants: SwiGLU and GeGLU
Embedding scaling
multiplying a looked-up embedding by √d_model before it is combined with positional information. from Token Embeddings and Embedding Scaling
Embedding table
the lookup matrix mapping each vocabulary entry to a vector, sized vocabulary_size × d_model. from Vocabulary Size and Out-of-Vocabulary Trade-offs
a vocabulary_size × d_model matrix, one row per token, learned during training. from Token Embeddings and Embedding Scaling
Encoder-decoder architecture
a transformer combining a bidirectional encoder stack, a causal decoder stack, and cross-attention connecting them. from Encoder-Decoder Architectures as a Pattern
Encoder-only
a transformer architecture using only padding masking, with no causal restriction — every position attends to every other. from Encoder-Only Architectures
End-of-word marker
a symbol marking where one word ends, preventing merges across word boundaries. from Byte Pair Encoding
End-to-end
covering every stage from raw input to final output, with no stage skipped or special-cased. from Capstone: Assembling a Tiny Transformer from the Ground Up
Expansion-then-projection
widening a vector to a larger hidden dimension before compressing it back to the original width. from The Feed-Forward Sublayer
Expert
one of several parallel feed-forward sublayers in a mixture-of-experts block. from Mixture-of-Experts Transformer Blocks
Feature map (φ)
a function applied to queries and keys in place of softmax, chosen to make the linear-order computation valid. from Linear Attention Approximations
FLOPs (floating-point operations)
a measure of computational work, roughly proportional to parameter count for one forward pass through a token. from Counting a Transformer's Parameters and FLOPs
Gate
a projection passed through an activation function, controlling how much of a parallel projection's value passes through. from Modern Feed-Forward Variants: SwiGLU and GeGLU
Grouped-query attention (GQA)
sharing one key/value projection per group of heads, a middle ground between standard multi-head attention and MQA. from Multi-Query and Grouped-Query Attention
IO-aware
designed around minimizing data movement between slow and fast memory, not just minimizing arithmetic operations. from IO-Aware Attention Computation
KV cache
stored keys and values for every token generated so far, reused instead of recomputed at each new step. from KV-Caching for Autoregressive Inference
Latency
the total time a single request takes, including both time spent waiting to be batched and time spent being processed. from Inference Serving Trade-offs
Length extrapolation
a model's ability to behave sensibly on sequences longer than anything seen during training. from ALiBi and Length Extrapolation
Linear attention
an attention computation reorganized to scale linearly, rather than quadratically, with sequence length. from Linear Attention Approximations
Linear bias
a penalty that grows proportionally with distance, subtracted directly from an attention score. from ALiBi and Length Extrapolation
Local attention
attention restricted to a neighbourhood around each position, instead of the full sequence. from Sparse and Local (Windowed) Attention
Logit
an unnormalized score for one vocabulary entry, before any softmax turns it into a probability. from Weight Tying
Lossless tokenization
a scheme where the original text can be exactly reconstructed from its tokens, with no ambiguity about spacing. from WordPiece and SentencePiece
Masked language modeling (MLM)
a training objective that predicts a masked-out token from its surrounding bidirectional context. from Encoder-Only Architectures
Masked score
an attention score set to negative infinity before the softmax, guaranteeing zero attention weight. from Attention Masks: Padding and Causal Masking
max_length
the largest sequence position a learned positional table has an entry for. from Learned Positional Embeddings
Merge
combining the most frequent adjacent symbol pair into one new symbol, BPE's single training step. from Byte Pair Encoding
Message passing
a GNN's mechanism for propagating information only between directly connected nodes. from Graph Transformers
Modality
a type of data (text, image, audio) that can be converted into a token sequence its own way. from Tokenizing Beyond Text
a type of input data (text, image, audio) with its own front-end producing vectors of a shared width. from Multimodal Transformers as an Architecture Pattern
Multi-query attention (MQA)
sharing a single key/value projection across every attention head. from Multi-Query and Grouped-Query Attention
Non-embedding parameters
a model's parameters excluding the embedding table, often reported separately in scaling-law analysis. from Counting a Transformer's Parameters and FLOPs
num_kv_heads
the number of distinct key/value projections, which can be fewer than the number of query heads. from Multi-Query and Grouped-Query Attention
Online (running) softmax
computing softmax incrementally over blocks, using a running maximum and sum, instead of requiring the full row at once. from IO-Aware Attention Computation
Output projection
the matrix mapping a final hidden state to a score (logit) for every vocabulary entry. from Weight Tying
Padding mask
blocks every query from attending to positions that are only padding, not real tokens. from Attention Masks: Padding and Causal Masking
Patch
a fixed-size, non-overlapping square region of an image, flattened into one vector. from Tokenizing Beyond Text
Patch embedding
a learned linear projection turning a flattened image patch into a model-width vector. from Vision Transformers
Patchifying
cutting an input into fixed-size pieces as a deterministic alternative to learned tokenization. from Tokenizing Beyond Text
Pipeline
the ordered sequence of stages — tokenization, embedding, transformer blocks, output projection — that turns raw text into a prediction. from Capstone: Assembling a Tiny Transformer from the Ground Up
Position-wise
applied identically and independently to each position in a sequence, with no mixing between positions. from The Feed-Forward Sublayer
Positional table
a trained embedding table indexed by sequence position instead of token id. from Learned Positional Embeddings
Post-norm
normalizing the sum of a sublayer's input and output, after they're added together. from Layer Normalization Placement: Pre-Norm vs Post-Norm
Pre-norm
normalizing only the copy of the input fed into a sublayer, leaving the residual stream itself unnormalized. from Layer Normalization Placement: Pre-Norm vs Post-Norm
Quadratic recomputation
the wasted cost of recomputing every earlier token's key and value at every single generation step, without caching. from KV-Caching for Autoregressive Inference
Relative position
positional information expressed as the distance between two tokens, rather than either token's absolute index. from Relative Position and RoPE
Residual connection
adding a sublayer's input to its output, instead of replacing the input entirely. from Residual Connections in Transformers
Residual stream
the running sum of contributions carried forward through a stack of residual-connected layers. from Layer Normalization Placement: Pre-Norm vs Post-Norm
RMSNorm
normalization that rescales a vector by its root-mean-square, without subtracting the mean. from RMSNorm vs LayerNorm
Root-mean-square
the square root of a vector's mean squared value, √(mean(x²)). from RMSNorm vs LayerNorm
Rotary position embedding (RoPE)
a positional scheme that rotates queries and keys so attention scores depend only on relative distance. from Relative Position and RoPE
Rotation angle
the position-proportional angle RoPE uses to rotate a vector's paired dimensions. from Relative Position and RoPE
Router
a small learned network that scores each expert for a given input and selects the top few. from Mixture-of-Experts Transformer Blocks
Sequence-to-sequence
a task that transforms one complete input sequence into a different output sequence, such as translation. from Encoder-Decoder Architectures as a Pattern
Sequence-to-sequence task
a task whose output is a genuine transformation of a separate input, the natural fit for encoder-decoder. from Choosing an Architecture Family for a Task
Shortest-path distance
the minimum number of edges connecting two nodes in a graph, computed via breadth-first search. from Graph Transformers
Signal preservation
how much of an original input's information survives after passing through many layers. from Residual Connections in Transformers
Slope
a fixed, per-head constant controlling how steeply ALiBi's bias penalizes distance. from ALiBi and Length Extrapolation
Stacking
repeating the same block structure many times, with independently trained weights at each depth, to build a full transformer. from Assembling One Transformer Block
Structural bias
an attention-score adjustment based on graph structure, used in place of a hard adjacency mask. from Graph Transformers
Sublayer
one of the two main computations inside a transformer block — the attention sublayer or the feed-forward sublayer. from Residual Connections in Transformers
one of the two main computations (attention or feed-forward) inside a transformer block. from Assembling One Transformer Block
Subword token
a vocabulary entry smaller than a whole word but larger than a single character. from Byte Pair Encoding
SwiGLU / GeGLU
gated feed-forward designs using SiLU or GELU, respectively, as the gating activation. from Modern Feed-Forward Variants: SwiGLU and GeGLU
Task shape
whether a task has no generated output, one continuous growing sequence, or two separate input/output sequences. from Choosing an Architecture Family for a Task
Tensor parallelism
splitting a single weight matrix's rows or columns across multiple devices. from Splitting a Transformer Across Devices
Throughput
the rate at which requests are processed, typically requests or tokens per second. from Inference Serving Trade-offs
Tokens per word
how many vocabulary entries, on average, one word decomposes into — falls as vocabulary size grows. from Vocabulary Size and Out-of-Vocabulary Trade-offs
Transformer block
the repeated unit of a transformer, containing one attention sublayer and one feed-forward sublayer, each wrapped in normalization and a residual connection. from Assembling One Transformer Block
Untrained weights
randomly initialized parameters, used here to verify the pipeline's mechanics rather than to produce a meaningful prediction. from Capstone: Assembling a Tiny Transformer from the Ground Up
Vision Transformer (ViT)
a transformer applied to image patches, using no convolutional layers. from Vision Transformers
Vocabulary size
the total number of distinct entries a tokenizer can produce, set by how many merges (or equivalent) its training ran for. from Vocabulary Size and Out-of-Vocabulary Trade-offs
Weight tying
reusing the input embedding table as the output projection instead of training a separate matrix. from Weight Tying
Whitespace marker (▁)
a visible symbol standing in for a space, letting SentencePiece treat spaces as ordinary, mergeable symbols. from WordPiece and SentencePiece
Window radius
the fixed distance within which a position may attend to its neighbours under windowed attention. from Sparse and Local (Windowed) Attention
