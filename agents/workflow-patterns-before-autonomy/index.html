Workflow Patterns Before Autonomy

Agents1 min read

Not every multi-step task needs a fully autonomous agent deciding what to do next. A fixed sequence of LLM calls, wired together by code the developer controls, solves most well-defined tasks more predictably and more cheaply than letting a model improvise the whole plan. This district covers those structured patterns, which stay the right choice right up until a task is genuinely open-ended.

Topics on this stretch of the road:

  • Prompt Chaining: splitting one task into a fixed sequence of smaller LLM calls.
  • Routing Between Specialized Prompts: sending a request to whichever of several specialized prompts actually fits it.
  • Parallelization: Sectioning and Voting: running several LLM calls at once, either on different pieces of a task or on the same piece for a better answer.
  • Orchestrator-Workers: one call that plans the work, several calls that do it, and one call that combines the results.
  • Evaluator-Optimizer Loops: one call that produces an answer, another that critiques it, looping until the critique is satisfied.

Prompt Chaining

Splitting a task into a fixed sequence of calls — outline, then draft, then polish — lets each step check the previous one's work before building on it.

Routing Between Specialized Prompts

One generic handler answering every kind of request is simpler to build than several specialists — and noticeably worse at any one of them.

Parallelization: Sectioning and Voting

Running three independent pieces of a task one after another wastes time that didn't need to be spent sequentially at all — none of the three pieces needed the others to finish first.

Orchestrator-Workers

A single call asked to analyze a market, project financials, and assess risk, all in one response, often trails off after the first section or two — there was only so much the model would produce…

Evaluator-Optimizer Loops

A first draft critiqued once gets noticeably better; critiqued a second time, it gets better still, but by less than the first round did.
