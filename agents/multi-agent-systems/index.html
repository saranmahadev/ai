Multi-Agent Systems

Agents1 min read

One agent can only hold one line of thought at a time. Splitting a task across several agents — each specialized, each potentially working in parallel — can get more done, but only if they're coordinated well enough that the pieces actually fit back together. This section is about the concrete patterns for wiring several agents together, and the specific ways that wiring can fail.

Topics in this section:

  • Supervisor/Orchestrator Patterns: one agent that routes work to specialists and never lets them talk to each other directly.
  • Pipeline and Sequential Handoff: a fixed chain of agents, each one handing its output to the next.
  • Swarm and Peer-to-Peer Coordination: agents that coordinate directly through shared state, with no central router.
  • Debate and Adversarial Multi-Agent Setups: agents arguing opposite sides of a question to surface a better answer than either alone.
  • Role Specialization in Agent Teams: giving each agent in a team a distinct job, instead of running identical copies of the same prompt.
  • Coordination Failures and Deadlock: the specific ways a multi-agent system gets stuck, talks past itself, or duplicates work.

Supervisor-Orchestrator Patterns

A supervisor agent never does the specialized work itself — it decides which specialist should handle a piece of a task, hands it off, and collects the result.

Pipeline and Sequential Handoff

A research agent hands its findings to a drafting agent, which hands its draft to a review agent, which hands its approval to a finalizing agent.

Swarm and Peer-to-Peer Coordination

Remove the supervisor from a star topology and every specialist loses its only connection to the rest of the system at once.

Debate and Adversarial Multi-Agent Setups

A single agent that states a claim has no one checking its arithmetic.

Role Specialization in Agent Teams

Three identical copies of the same generalist agent are each mediocre at every required skill.

Coordination Failures and Deadlock

Two agents, each waiting on a result only the other can produce, aren't making progress — they're stuck in a circular wait.
