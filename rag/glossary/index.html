Glossary

RAG Glossary

142 terms from RAG.

A/B testing
comparing two system variants by routing real traffic to each and measuring an outcome metric. from A-B and Online Evaluation of RAG
Adaptation strategy
the general choice of mechanism (retrieval, fine-tuning, long-context, or some combination) used to close a gap between a model's default behavior and what a task needs. from RAG vs. Fine-Tuning vs. Long-Context
Aggregate
a computed value (count, sum, average) across multiple rows, as opposed to a single retrieved record. from Retrieval over Structured Data
Answer relevancy
how closely a generated answer's embedding matches the question's embedding. from Faithfulness and Answer Relevancy Metrics
Approximation trade-off
accepting a small risk of missing the true closest results in exchange for a large reduction in search cost. from Exact Nearest Neighbor Search
Assembly
arranging retrieved passages into the prompt the model will actually generate from. from Anatomy of a RAG Pipeline
Assembly order
the specific sequence in which retrieved passages are placed within the assembled context. from Context Assembly and Ordering
Bi-encoder
an encoder applied independently to the query and to each document, enabling document vectors to be precomputed. from Bi-Encoders and Dense Embeddings
BM25
a smoothed, saturating refinement of TF-IDF widely used as a strong sparse-retrieval baseline. from Sparse Retrieval with TF-IDF and BM25
Boilerplate
text that repeats across a document's pages or sections without carrying page-specific content (headers, footers, page numbers). from Parsing Documents for Retrieval
Boundary-straddling fact
a piece of information that falls across where a chunk boundary happens to land, risking being split and lost. from Chunk Overlap and Size Trade-offs
Budget collapse
the point at which growing conversation history leaves too little room for retrieved content to contribute meaningfully. from Context-Window Budgeting for RAG
Cache hit rate
the fraction of requests that can be served from the cache rather than requiring full computation. from Caching and Incremental Indexing
Caching
storing and reusing the result of a previous computation (a query's answer, an embedding) instead of recomputing it. from Caching and Incremental Indexing
Centroid
the representative center point of a cluster, used to decide which cluster a query or vector belongs to. from Approximate Nearest Neighbor Search with IVF and Product Quantization
Chunk boundary
the point where one chunk ends and the next begins. from Fixed-Size and Recursive Chunking
Citation
linking a specific claim in a generated answer to the retrieved passage that supports it. from Citation and Source Attribution
Citation threshold
the minimum similarity a claim's best-matching passage must reach to be cited rather than flagged unsupported. from Citation and Source Attribution
Confidence decay
the gradual drop in reliability of a model's unretrieved answers as a question moves further past its training cutoff. from Hallucination and Knowledge Cutoff
Conflicting context
two or more retrieved passages that answer the same question with different, incompatible information. from Handling Noisy or Conflicting Retrieved Context
Context assembly
arranging retrieved passages into the final prompt sent to the generating model. from Context Assembly and Ordering
Context budget
the fixed total token capacity available for a single request's prompt. from Context-Window Budgeting for RAG
Context noise
retrieved content that is irrelevant, contradictory, or otherwise unhelpful once it reaches generation. from Handling Noisy or Conflicting Retrieved Context
Context precision/recall
retrieval-side metrics measuring how much of the retrieved context is relevant, and how much of the relevant content was retrieved. from End-to-End RAG Evaluation Frameworks
Corrective RAG
classifying a retrieval's overall quality and routing to different corrective actions based on that classification. from Corrective RAG
Coverage
the fraction of a corpus that has at least one associated evaluation question. from Synthetic Test-Set Generation for RAG
Cross-encoder
a model that jointly processes a query and a document together to produce a single relevance score. from Cross-Encoders and Re-Rankers
Cross-modal similarity
a similarity score computed between embeddings from two different modalities. from Multimodal RAG
Data leakage
unauthorized content reaching a user through a system that wasn't supposed to grant them access to it. from Security and Data Leakage in RAG
Dense embedding
a vector representation (as opposed to a sparse, word-count-based one) produced by an encoder like a bi-encoder. from Bi-Encoders and Dense Embeddings
Dense retrieval
ranking documents by embedding (cosine) similarity to a query, rather than exact vocabulary overlap. from Dense Retrieval
Domain adaptation
fine-tuning a general-purpose model on data from a specific domain so it better reflects that domain's vocabulary and conventions. from Domain-Adapting Embedding Models
End-to-end evaluation framework
a combined scorecard covering both retrieval-side and generation-side metrics. from End-to-End RAG Evaluation Frameworks
End-to-end trace
following one request through every stage of a pipeline in order, rather than examining each stage in isolation. from Capstone: A Question Answered, Traced from Query to Grounded Answer
Entity extraction
identifying entities and relationships from raw documents to build a knowledge graph in the first place. from Graph-Based RAG
Exact nearest neighbor search
finding the true closest vectors to a query by comparing against every vector in the collection. from Exact Nearest Neighbor Search
Failure mode
a recurring, recognizable way a RAG system produces a bad result. from Common RAG Failure Modes
Faithfulness
the fraction of a generated answer's claims that are supported by retrieved context. from Grounded Generation and Faithfulness
the fraction of an answer's claims grounded in retrieved context (covered in depth in Grounded Generation and Faithfulness). from Faithfulness and Answer Relevancy Metrics
Fallback action
an alternative strategy (query refinement, broader search) triggered when a retrieval is judged too weak to generate from directly. from Corrective RAG
Fixed-size chunking
splitting text at a constant character or token count, regardless of word or sentence boundaries. from Fixed-Size and Recursive Chunking
Flattening
converting structured content into unstructured prose, discarding the structure in the process. from Handling Tables, Code and Structured Content
Freshness
how quickly a change in the real world can be reflected in a system's answers. from RAG vs. Fine-Tuning vs. Long-Context
Freshness filter
a metadata-based filter that excludes chunks older than a given cutoff date. from Metadata Extraction and Enrichment
Freshness-based resolution
resolving a conflict by keeping the most recently dated passage and discarding the others. from Handling Noisy or Conflicting Retrieved Context
Fusion constant (k)
a smoothing parameter in RRF that softens the effect of small rank differences near the top. from Hybrid Retrieval Fusion
Graded relevance
a relevance score with more than two levels (not just relevant/irrelevant), as NDCG uses. from Retrieval Metrics: Precision, Recall, MRR and NDCG
Graph traversal
following edges from one entity to the next to answer a question spanning multiple relationships. from Graph-Based RAG
Greedy search
repeatedly moving to whichever linked neighbor is closest to the query, stopping once no neighbor improves on the current position. from Approximate Nearest Neighbor Search with HNSW
Grounded answer
a generated answer whose claims are verifiably supported by retrieved context. from Capstone: A Question Answered, Traced from Query to Grounded Answer
Grounded generation
generation that draws its claims from retrieved context rather than unretrieved, pretrained knowledge. from Grounded Generation and Faithfulness
Hallucination
a model producing a confident, fluent answer that is factually wrong. from Hallucination and Knowledge Cutoff
HNSW (Hierarchical Navigable Small World)
an approximate nearest-neighbor method based on greedy search over a graph of linked vectors. from Approximate Nearest Neighbor Search with HNSW
Hop
one retrieval pass within a multi-hop chain. from Multi-Hop and Iterative Retrieval
Hybrid index
an index combining metadata filtering with vector similarity search, supporting efficient pre-filtering. from Metadata Filtering and Hybrid Indexes
Hybrid retrieval
combining sparse and dense retrieval into a single ranking. from Hybrid Retrieval Fusion
HyDE (Hypothetical Document Embeddings)
embedding a generated hypothetical answer instead of the bare query, to better match the phrasing of real documents. from Hypothetical Document Embeddings (HyDE)
Hypothetical answer
a plausible, not-necessarily-correct generated response used only to improve retrieval, not shown to the user. from Hypothetical Document Embeddings (HyDE)
In-domain training pairs
(query, relevant passage) examples drawn from the specific domain a model is being adapted to. from Domain-Adapting Embedding Models
Incremental indexing
adding new documents to an existing index at a cost proportional to what's added, not the whole collection. from Caching and Incremental Indexing
Independent failure modes
two ways an answer can go wrong that don't imply or predict each other. from Faithfulness and Answer Relevancy Metrics
Index persistence
storing a built index to disk so it survives a restart without being rebuilt from scratch. from Vector Databases and Index Management
int8
an 8-bit (1-byte) integer representation, commonly used as a quantization target for embeddings originally stored as 32-bit floats. from Embedding Quantization for Retrieval
Intermediate fact
a piece of information retrieved not because it directly answers the question, but because it's needed to form the next search. from Multi-Hop and Iterative Retrieval
IVF (inverted file index)
an index that clusters vectors ahead of time and searches only the clusters nearest a query. from Approximate Nearest Neighbor Search with IVF and Product Quantization
Joint encoding
processing two inputs together, allowing interactions between them, as opposed to encoding each independently. from Cross-Encoders and Re-Rankers
Knowledge graph
a structure of entities and labeled relationships (edges) between them. from Graph-Based RAG
Late interaction
comparing query and document representations at the token level at query time, after both were encoded independently. from Multi-Vector and Late-Interaction Retrieval
Latency breakdown
how a request's total time is divided among its constituent stages. from Production RAG Pipeline Architecture
Linear scan
checking every item in a collection one by one, with cost proportional to collection size. from Exact Nearest Neighbor Search
Long-context
supplying potentially relevant information directly in the prompt rather than searching for it, limited by the context window and its per-request cost. from RAG vs. Fine-Tuning vs. Long-Context
Long-range link
a graph edge connecting distant regions, letting a search cross large distances in a single hop. from Approximate Nearest Neighbor Search with HNSW
Lost-in-the-middle effect
the tendency for information in the middle of a long context to be used less reliably than information at the start or end. from Context Assembly and Ordering
MaxSim
scoring by summing, for each query token, its single highest similarity to any document token. from Multi-Vector and Late-Interaction Retrieval
Metadata
structured information about a chunk (date, source, section, permissions) kept separate from its searchable text. from Metadata Extraction and Enrichment
MRR (mean reciprocal rank)
the reciprocal of the position of the first relevant result in a ranking. from Retrieval Metrics: Precision, Recall, MRR and NDCG
Multi-hop retrieval
chaining multiple retrieval passes, where a later search uses an earlier search's result as its query. from Multi-Hop and Iterative Retrieval
Multi-vector retrieval
representing a document as multiple token-level embeddings instead of one pooled vector. from Multi-Vector and Late-Interaction Retrieval
Multimodal RAG
retrieval where the query and the retrieved content are in different modalities (text and images, for instance). from Multimodal RAG
NDCG (normalized discounted cumulative gain)
a ranking metric using graded relevance, discounted by position, normalized against the ideal ordering. from Retrieval Metrics: Precision, Recall, MRR and NDCG
Near-duplicate chunks
chunks with very similar or identical text that differ in some attribute, such as when they were last updated. from Metadata Extraction and Enrichment
NL-to-query translation
converting a natural-language question into a structured query's filter and operation. from Retrieval over Structured Data
Noise fraction
the share of a raw extraction that turns out to be boilerplate rather than real content. from Parsing Documents for Retrieval
Non-parametric knowledge
information kept in an external, searchable store, updatable immediately without touching the model. from Parametric vs. Non-Parametric Knowledge
Online evaluation
measuring a system against real user behavior, as opposed to a fixed offline test set. from A-B and Online Evaluation of RAG
Overlap
the number of characters (or tokens) repeated between the end of one chunk and the start of the next. from Chunk Overlap and Size Trade-offs
Parametric confidence
the model's own estimate of how likely its unretrieved answer is to be correct. from Self-RAG and Reflective Retrieval
Parametric knowledge
information implicitly stored in a model's trained weights, updatable only by retraining. from Parametric vs. Non-Parametric Knowledge
Parsing
converting a document's native format into clean text suitable for chunking. from Parsing Documents for Retrieval
Permission filtering
restricting retrieval to only chunks a given user is authorized to see. from Security and Data Leakage in RAG
Phrasing mismatch
the stylistic gap between how a question is phrased and how its answer is phrased, which hurts a bare query's embedding similarity to the real answer. from Hypothetical Document Embeddings (HyDE)
Pipeline architecture
the overall design of how a RAG system's stages connect and hand off to each other. from Production RAG Pipeline Architecture
Post-filtering
applying a metadata filter after an ANN search has already produced its top-k results by similarity. from Metadata Filtering and Hybrid Indexes
Pre-filtering
applying a metadata filter before similarity search, ranking only among already-eligible candidates. from Metadata Filtering and Hybrid Indexes
Precision/recall trade-off
the cost of expansion — more matching terms can mean more irrelevant matches too. from Query Expansion and Rewriting
Precomputation
computing and storing document vectors once, ahead of any specific query. from Bi-Encoders and Dense Embeddings
Product quantization
compressing vectors within a cluster to speed up and shrink the memory of searching inside it. from Approximate Nearest Neighbor Search with IVF and Product Quantization
Production pipeline
the full chain of stages (embed, search, re-rank, assemble, generate) a real RAG system runs per request. from Production RAG Pipeline Architecture
Prompt injection via retrieved content
a retrieved document containing text designed to redirect the generating model's behavior. from Security and Data Leakage in RAG
Quantization
representing each value in a vector with fewer bits, trading precision for reduced memory. from Embedding Quantization for Retrieval
Query
the user's raw question before any processing. from Anatomy of a RAG Pipeline
Query expansion
adding related terms to a query before retrieval, to compensate for exact-vocabulary matching limitations. from Query Expansion and Rewriting
Question-answer triple
a generated question paired with its expected answer and the source chunk it was derived from. from Synthetic Test-Set Generation for RAG
RAG overhead
the added latency a RAG pipeline introduces on top of a plain generation call. from Cost and Latency of RAG Systems
Re-ranker
a (typically cross-encoder) model applied to a short list of already-retrieved candidates to reorder them more accurately. from Cross-Encoders and Re-Rankers
Re-ranking
applying a more accurate (and more expensive) scoring method to a shortlist a cheaper method already produced. from Re-Ranking Retrieved Results
Reciprocal rank fusion (RRF)
a fusion method that combines rankings using each candidate's rank position, not its raw score. from Hybrid Retrieval Fusion
Recursive chunking
splitting on structural units (paragraphs, sentences) and packing them up to a size limit without ever cutting one in half. from Fixed-Size and Recursive Chunking
Redundancy
the fraction of total stored characters that are duplicates caused by overlap. from Chunk Overlap and Size Trade-offs
Relative overhead
added latency expressed as a percentage of the baseline (plain call) latency, which shifts as the baseline itself changes. from Cost and Latency of RAG Systems
Relevance check
a self-assessment of whether a retrieved passage actually bears on the question asked. from Self-RAG and Reflective Retrieval
Replication
maintaining copies of an index across multiple machines for availability and scale. from Vector Databases and Index Management
Retrieval verdict
the bucket (correct, ambiguous, incorrect) a retrieval is classified into. from Corrective RAG
Retrieval-augmented generation (RAG)
combining a model's parametric knowledge with non-parametric knowledge fetched from a document store at answer-time. from Parametric vs. Non-Parametric Knowledge
Retrieval-side latency
the time spent on embedding, searching, and re-ranking, as opposed to generation itself. from Cost and Latency of RAG Systems
Root cause
the underlying pipeline stage responsible for a surface-level symptom. from Common RAG Failure Modes
Row-preserved chunking
keeping each structural unit (a table row, a function) as its own chunk. from Handling Tables, Code and Structured Content
Scale factor
the value used to convert between a quantized integer and its original floating-point range. from Embedding Quantization for Retrieval
Self-RAG
a RAG variant where the model itself decides whether to retrieve and whether to trust what was retrieved. from Self-RAG and Reflective Retrieval
Semantic chunking
placing chunk boundaries where consecutive sentences' embedding similarity drops, rather than at a fixed size. from Semantic and Structure-Aware Chunking
Semantic matching
finding content related in meaning, even without shared surface vocabulary. from Dense Retrieval
Sense ambiguity
a term having multiple distinct meanings, with the correct one depending on context or domain. from Domain-Adapting Embedding Models
Shared embedding space
a vector space where content from multiple modalities is embedded so that semantically related items land close together regardless of modality. from Multimodal RAG
Shortlist
the reduced set of candidates passed from a cheap retrieval stage to an expensive re-ranking stage. from Re-Ranking Retrieved Results
the reduced set of candidates retrieval passes on to re-ranking. from Capstone: A Question Answered, Traced from Query to Grounded Answer
Similarity threshold
the cutoff below which two consecutive sentences are considered different enough to warrant a chunk boundary. from Semantic and Structure-Aware Chunking
Source attribution
the broader practice of tracing generated content back to its retrieved origins. from Citation and Source Attribution
Sparse retrieval
ranking documents by weighted exact-term overlap with a query, as opposed to embedding-based similarity. from Sparse Retrieval with TF-IDF and BM25
Stage localization
identifying which specific pipeline stage (retrieval vs. generation) a low score points to. from End-to-End RAG Evaluation Frameworks
Statistical significance
whether an observed difference is large enough, relative to sample size, to be distinguishable from random noise. from A-B and Online Evaluation of RAG
Structure-aware chunking
splitting at a document's own structural markers (headings, paragraphs) instead of computing similarity. from Semantic and Structure-Aware Chunking
Structured content
content whose meaning depends on an explicit structure (tables, code, forms) rather than flowing prose. from Handling Tables, Code and Structured Content
Structured query
a precise, executable filter or aggregate operation run directly against structured data. from Retrieval over Structured Data
Symptom-to-fix mapping
associating an observed problem with the specific pipeline stage and technique that addresses it. from Common RAG Failure Modes
Synonym
a word with a similar meaning used to expand a query's matching vocabulary. from Query Expansion and Rewriting
Synthetic test-set generation
automatically producing (question, answer, source) evaluation triples from a document collection. from Synthetic Test-Set Generation for RAG
TF-IDF
a term-weighting scheme combining term frequency and inverse document frequency. from Sparse Retrieval with TF-IDF and BM25
Token allocation
how a fixed budget is divided between competing consumers (conversation history, retrieved chunks). from Context-Window Budgeting for RAG
Top-k
the number of highest-scoring documents kept after retrieval, out of the full collection. from Anatomy of a RAG Pipeline
Training cutoff
the date after which no data existed in a model's training set. from Hallucination and Knowledge Cutoff
Two-stage retrieval
a pipeline combining a fast, broad first pass with a slow, narrow second pass. from Re-Ranking Retrieved Results
Unsupported claim
a generated claim with no sufficiently similar retrieved passage backing it. from Grounded Generation and Faithfulness
Vector database
a system that wraps an ANN search algorithm with insert/update/delete support, persistence, metadata filtering and replication. from Vector Databases and Index Management
Vocabulary mismatch
the gap between how a query and a relevant document happen to express the same idea in different words. from Dense Retrieval
