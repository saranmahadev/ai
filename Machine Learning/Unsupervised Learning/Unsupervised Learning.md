When no answers are given, a model can still find structure: groups of similar points, the true number of dimensions in the data, or the odd ones out. This district covers clustering by centres, choosing how many clusters there are, clustering by merging, soft clustering with probabilities, compressing data with PCA, and finding anomalies.

Topics on this stretch of the road:

* [[k-Means Clustering]]: assign, move, repeat.
* [[Choosing the Number of Clusters]]: the elbow and the silhouette.
* [[Hierarchical Clustering]]: a merge tree cut at any height.
* [[Gaussian Mixtures and EM]]: soft clusters with bell curves.
* [[Dimensionality Reduction in Practice]]: keeping the components that matter.
* [[Anomaly Detection]]: modelling normal to find the unusual.
