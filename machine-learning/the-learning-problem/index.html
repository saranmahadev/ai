The Learning Problem

Machine Learning1 min read

This section frames the whole subject: what it means for a program to learn from examples, the kinds of feedback a learner can have, how a dataset is laid out, why data must be split before judging a model, and the loop that actually changes a model's numbers. Everything later in machine learning is a variation on these five ideas.

What Is Machine Learning

Machine learning is building a program by showing it examples instead of writing its rules.

Kinds of Learning

Machine learning problems come in three main flavours, defined by the feedback the learner gets. In supervised learning every example comes with the right answer.

Datasets, Features and Labels

A dataset is a table: each row is an example, each column a measurement. The columns the model reads are features; the column it should predict is the label (or target).

Train, Validation and Test Sets

To know whether a model works you must measure it on data it has not learned from.

The Learning Loop

Training a model is a loop: predict with the current parameters, measure the loss, work out which way each parameter should move to lower it, nudge the parameters, and repeat.

Machine Learning

Machine learning is the craft of building programs from examples. Instead of writing the rules, you show a model data, tell it what "good" means, and let it find the rules itself.
