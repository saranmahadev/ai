Unsupervised Learning

Machine Learning1 min read

When no answers are given, a model can still find structure: groups of similar points, the true number of dimensions in the data, or the odd ones out. This section covers clustering by centres, choosing how many clusters there are, clustering by merging, soft clustering with probabilities, compressing data with PCA, and finding anomalies.

Topics in this section:

  • k-Means Clustering: assign, move, repeat.
  • Choosing the Number of Clusters: the elbow and the silhouette.
  • Hierarchical Clustering: a merge tree cut at any height.
  • Gaussian Mixtures and EM: soft clusters with bell curves.
  • Dimensionality Reduction in Practice: keeping the components that matter.
  • Anomaly Detection: modelling normal to find the unusual.

k-Means Clustering

k-means groups unlabelled points into k clusters by repeating two steps: assign every point to its nearest centre, then move each centre to the average of its points.

Choosing the Number of Clusters

Clustering algorithms need you to say how many clusters there are, but the data rarely says.

Hierarchical Clustering

Hierarchical clustering does not fix the number of clusters in advance. It starts with every point alone and repeatedly merges the two closest groups, recording each merge and its distance.

Gaussian Mixtures and EM

k-means gives each point to exactly one cluster. A Gaussian mixture is softer: it says the data came from several bell-curve groups and gives each point a probability of belonging to each.

Dimensionality Reduction in Practice

Real data often has many columns that mostly move together, so its true variety is far smaller than its width suggests.

Anomaly Detection

Anomaly detection looks for the rare points that do not fit: a fraudulent payment, a failing machine, a corrupt record.
