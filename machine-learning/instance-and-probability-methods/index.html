Instance and Probability Methods

Machine Learning1 min read

Not every learner fits a formula. Some remember examples and compare new ones with them; others count how often things happen and apply Bayes' rule; others lift the data into a space where a straight cut suffices. This section covers nearest neighbours, naive Bayes and its text application, the difference between modelling the classes and modelling the boundary, and kernels.

Topics in this section:

  • k-Nearest Neighbours: classify by asking the closest examples.
  • Naive Bayes: multiply the evidence for each class.
  • Text Classification with Naive Bayes: word counts, smoothing and spam.
  • Generative vs Discriminative Models: modelling the classes or the boundary.
  • Kernel Methods: curved boundaries from straight cuts in a lifted space.

k-Nearest Neighbours

k-nearest neighbours (kNN) classifies a new point by finding the k training points closest to it and letting them vote. There is no training step: the model is the data.

Naive Bayes

Naive Bayes classifies by asking, for each class, how well the observed features fit it, then combining the answers with Bayes' rule.

Text Classification with Naive Bayes

Text is the classic home of naive Bayes.

Generative vs Discriminative Models

There are two ways to build a classifier. A generative model learns what each class looks like (how its examples are distributed) and uses Bayes' rule to decide.

Kernel Methods

A straight line cannot separate every problem, but a straight line in a richer space can.

Machine Learning

Machine learning is the craft of building programs from examples. Instead of writing the rules, you show a model data, tell it what "good" means, and let it find the rules itself.
