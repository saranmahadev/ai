Bias, Fairness and Failure

Machine Learning1 min read

Getting a good number on a test set is not the same as being trustworthy. This district covers how to diagnose whether a model needs more data or a better design, how bias enters through data, how to measure fairness and why its definitions conflict, what happens when the world shifts after training, and how to look inside a model to see what it relies on.

Topics on this stretch of the road:

  • Learning Curves: more data or a better model?
  • Bias in Data: whose data trained the model.
  • Fairness Metrics: several definitions that cannot all hold.
  • Distribution Shift: when the world moves after training.
  • Interpreting Models: shuffling features to see what matters.
