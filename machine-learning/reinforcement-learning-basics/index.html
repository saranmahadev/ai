Reinforcement Learning Basics

Machine Learning1 min read

Some problems come with no answer key, only a score after the fact. Reinforcement learning is about agents that learn to act from rewards. This section covers what a reward, a state and a policy are, how the value of a situation is defined and computed, the exploration trade-off in its simplest form, learning values from experience with Q-learning, and improving a policy directly with policy gradients.

Topics in this section:

  • Rewards, States and Policies: return, discounting and policies.
  • Value Functions: how good is it to be here?
  • Bandits and Exploration: try new things or stick with what works.
  • Q-Learning: learning action values from experience.
  • Policy Gradients: nudging the policy toward what paid.

Rewards, States and Policies

In reinforcement learning an agent is never told the right action. It acts, the world changes, and a reward arrives, often late. The agent's behaviour is a policy: a rule from state to action.

Value Functions

A value function answers "how good is it to be here?": the expected return an agent will collect from a state onward if it behaves well.

Bandits and Exploration

The simplest reinforcement problem has no states: several slot machines ("arms") with unknown average payouts, and you choose one each time.
