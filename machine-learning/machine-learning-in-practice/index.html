Machine Learning in Practice

Knowing the algorithms is half the craft. The other half is process: the order in which a project's steps must happen, the simple baselines and error analysis that tell you what to do next, the leaks that quietly inflate scores, how to watch a model after it ships, and a capstone that ties the whole subject together.

Topics in this section:

  • The ML Workflow: which step may touch which data.
  • Baselines and Error Analysis: compare, then dissect the mistakes.
  • Pipelines and Leakage: how noise looks like signal.
  • Deployment and Monitoring: watching a model after it ships.
  • Capstone Classifier End to End: every lesson in one small project.
