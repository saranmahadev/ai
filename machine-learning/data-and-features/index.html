Data and Features

Machine Learning1 min read

Models see numbers, not the world, so how data is cleaned and represented decides most of what a model can learn. This section covers the practical craft: dealing with holes and dirt, putting features on comparable scales, turning categories into numbers, creating better inputs, and the strange geometry of having too many dimensions.

Topics in this section:

  • Missing Values and Cleaning: blanks, outliers and why the reason matters.
  • Scaling and Normalisation: putting features on comparable footing.
  • Encoding Categories: integer codes, one-hot and their hidden claims.
  • Feature Engineering: making the pattern easier to see.
  • The Curse of Dimensionality: why more features can hurt.

Missing Values and Cleaning

Real datasets have holes, typos, duplicates and impossible values.

Scaling and Normalisation

Features measured in different units can have wildly different sizes: age in tens, income in tens of thousands.

Encoding Categories

Models do arithmetic, so categories such as "Paris" or "XL" must become numbers. The way you do it decides what the model thinks about them.

Feature Engineering

Feature engineering means creating better inputs from the raw columns: ratios, squares, counts, differences, dates unpacked into weekday and month.

The Curse of Dimensionality

Every feature you add is a new dimension, and high-dimensional space behaves strangely: it is enormous, data points end up far from everything, and "nearest" stops meaning much.

Machine Learning

Machine learning is the craft of building programs from examples. Instead of writing the rules, you show a model data, tell it what "good" means, and let it find the rules itself.
