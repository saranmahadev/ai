Linear Models

Machine Learning1 min read

Linear models compute a weighted sum of the features and either use it directly (regression) or squash it into a probability (classification). They are fast, transparent and surprisingly hard to beat on the right problem, and they are the ancestors of neural networks. This district covers fitting a line, turning scores into probabilities, taming many features with penalties, the first learning machine, and the widest-margin classifier.

Topics on this stretch of the road:

  • Linear Regression in Practice: fitting a line and reading its residuals.
  • Logistic Regression as a Classifier: probabilities, thresholds and the two kinds of error.
  • Ridge and Lasso: penalties that shrink weights and select features.
  • The Perceptron: learning from mistakes.
  • Support Vector Machines: the widest street between two classes.

Linear Regression in Practice

Linear regression predicts a number as a weighted sum of features plus a constant, with the weights chosen to minimise squared error.

Logistic Regression as a Classifier

Logistic regression turns a linear score into a probability with the sigmoid and predicts a class by comparing that probability with a threshold. Despite its name it is a classifier.

Ridge and Lasso

When there are many features and little data, a linear model can fit noise with huge, contradictory weights. Regularisation adds a penalty on the weights so the model prefers small ones.

Support Vector Machines

Many lines separate two classes, so which is best? A support vector machine picks the one with the widest empty street between the classes: the maximum margin.

Machine Learning

Machine learning is the craft of building programs from examples. Instead of writing the rules, you show a model data, tell it what "good" means, and let it find the rules itself.
