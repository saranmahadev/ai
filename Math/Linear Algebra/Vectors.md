# Vectors and Vector Notation

A **vector** is a mathematical object that represents **both magnitude and direction**.

For example:

* “Walk **5 km**” → only magnitude.
* “Walk **5 km north**” → magnitude **and** direction → **vector**.

Vectors are fundamental in physics, mathematics, computer graphics, robotics, machine learning, and AI.

---

## Scalar vs Vector

Before vectors, distinguish between **scalars** and **vectors**.

| Type       | Has magnitude | Has direction | Examples              |
| ---------- | ------------: | ------------: | --------------------- |
| **Scalar** |             ✅ |             ❌ | 5 kg, 20°C, 100 km/h  |
| **Vector** |             ✅ |             ✅ | 5 m east, 20 N upward |

A scalar is essentially **“how much.”**

A vector is **“how much + which way.”**

---

# What Does a Vector Look Like?

Imagine an arrow:

```text
O ───────────────► P
       5 units
```

The arrow represents a vector.

* Starting point: `O`
* Ending point: `P`
* Length of arrow → **magnitude**
* Arrow direction → **direction**

We might call this vector:

$$
\vec{OP}
$$

Read it as **“vector OP.”**
