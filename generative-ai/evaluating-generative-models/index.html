Evaluating Generative Models

Generative AI1 min read

A classifier has a right answer to check against; a generated poem or image usually doesn't. This section covers the metrics and methods built to judge generative output anyway, and what each one actually measures.

Topics in this section:

  • Perplexity as a Generation Metric: how surprised a language model is by text, and what that does and doesn't tell you.
  • n-gram Overlap Metrics (BLEU and ROUGE): scoring generated text by how much it overlaps with a reference.
  • Distributional Metrics (FID, Inception Score and CLIP Score): comparing generated and real data as whole distributions, not example by example.
  • Diversity and Mode Collapse in Generation: checking whether a generative model produces a genuinely varied range of outputs.
  • Human Evaluation of Generated Content: when automatic metrics aren't enough, and how human judgment is collected reliably.

Perplexity as a Generation Metric

A classifier's accuracy is easy to check: right or wrong.

n-gram Overlap Metrics (BLEU and ROUGE)

Perplexity measures how well a model predicts text it's shown; it says nothing about a model's own generated output compared to a correct answer.

Distributional Metrics (FID, Inception Score and CLIP Score)

BLEU and ROUGE work by comparing a generation directly against one specific reference.

Diversity and Mode Collapse in Generation

A generative model can score well on fidelity — every individual sample looks great — while quietly producing almost the same thing every time.

Human Evaluation of Generated Content

Every metric so far in this subject is automatic — computed from numbers, with no judgment involved.
