Video, 3D and Code Generation

Generative AI1 min read

Three modalities that each push generation past where images and audio stop: video adds time, 3D adds an extra spatial dimension and viewpoint consistency, and code adds a requirement neither has — the output must actually run.

Topics in this section:

  • Video Generation and Temporal Consistency: generating a sequence of frames that stays coherent from one frame to the next.
  • Video Editing and Interpolation: modifying existing footage or generating the frames between two given ones.
  • 3D Asset and Scene Generation: generating a three-dimensional object or scene instead of a flat image.
  • Code Generation and Program Synthesis: generating source code, and what makes that different from generating prose.
