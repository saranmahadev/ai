Deep Learning Glossary

207 terms from Deep Learning.

Accelerator
specialised hardware (GPUs, TPUs and others) built for the arithmetic patterns deep learning relies on. from Why GPUs and Accelerators
Accuracy-cost trade-off
balancing a candidate's performance against its compute, memory or latency cost. from Neural Architecture Search
Activation function
the non-linear function applied to a neuron's weighted sum. from The Artificial Neuron and Activation Functions
Activation maximization
optimising an input (rather than weights) to maximise a chosen unit's activation. from Feature Visualization
Adaptive step size
letting a solver choose smaller steps where accuracy requires it and larger steps where it doesn't. from Neural ODEs
Adversarial example
an input deliberately, minimally perturbed to damage a model's prediction. from Adversarial Examples and Robustness
Adversarial training
training two networks against each other's objectives simultaneously. from Generative Adversarial Networks
Alignment
which input positions a model attended to most strongly when producing a given output. from Encoder-Decoder Architectures with Attention
All-reduce
the communication step that averages gradients across all workers. from Distributed and Data-Parallel Training
Anchor, positive, negative
the reference example, its true match, and unrelated distractor examples in a contrastive training batch. from Contrastive Learning
Attention head
one independent attention computation with its own query, key and value projections. from Multi-Head Attention
Attention score
a measure of relevance between a decoder state and an encoder state. from Encoder-Decoder Architectures with Attention
Backbone
a pretrained architecture (often one of these) reused as the starting point for another vision task. from CNN Architectures: From LeNet to ResNet
Backpropagation through time (BPTT)
backpropagation applied to an RNN unrolled across its time steps. from Backpropagation Through Time
Baseline
a simple, well-understood model used as a starting comparison point before trying something more complex. from Choosing an Architecture for a Problem
the neutral reference input (often all zeros) integrated gradients measures attribution relative to. from Interpretability and Attribution
Batch normalization
normalizing a layer's activations using the current batch's mean and variance, then applying a learned scale and shift. from Batch Normalization
normalizing across the batch, for each feature (see Batch Normalization). from Layer Normalization
Batch size
the number of examples averaged into one gradient estimate. from Batch Size and Training Dynamics
Bidirectional RNN
two RNNs, one reading forward and one reading backward, with their hidden states combined at each position. from Bidirectional and Stacked RNNs
Bottleneck
the smallest, most compressed layer in an autoencoder, between the encoder and decoder. from Autoencoders
Bounding box
a rectangle, usually given by two corner coordinates, marking where a detected object is. from Object Detection and Segmentation
Breakpoint
a point where a piecewise-linear function's slope changes. from Why Depth Helps
Candidate content
the tanh-activated new information proposed for the cell state at each step. from Long Short-Term Memory
Candidate hidden state
the tanh-activated proposed new value, blended with the old state to produce the final hidden state. from Gated Recurrent Units
Cell state
an LSTM's long-term memory, updated additively through gates. from Long Short-Term Memory
Chain rule compounding
the multiplication of many per-layer factors that produces both effects. from Vanishing and Exploding Gradients
Change of variables
the probability formula relating a base distribution's density to a transformed distribution's density via the Jacobian determinant. from Normalizing Flows
Channel
one "layer" of a stack of feature maps (or of an input like RGB). from Filters, Feature Maps and Channels
Checkpoint
a saved snapshot of a model's weights, optimizer state and training progress. from Checkpointing and Reproducibility
Checkpoint interval
how many training steps elapse between saved checkpoints. from Checkpointing and Reproducibility
Clip by norm
rescaling the whole gradient vector to a maximum length, preserving direction. from Gradient Clipping
Clip by value
capping each component of the gradient independently. from Gradient Clipping
Communication overhead
the time cost of synchronising workers, which limits real-world speedup. from Distributed and Data-Parallel Training
Completeness
the property that attributions sum exactly to the change in output between the input and the baseline. from Interpretability and Attribution
Composition
applying a function to its own output, the mechanism depth exploits. from Why Depth Helps
Composition (of features)
building a new detector by combining the outputs of earlier, simpler detectors. from What Deep Networks Learn
Compression stack
combining multiple size-reduction techniques (pruning, quantization, distillation) together. from Edge and On-Device Deep Learning
Concatenation
joining the forward and backward hidden states into one combined vector per position. from Bidirectional and Stacked RNNs
Context vector (attention-based)
the weighted combination of encoder states, recomputed at every decoding step. from Encoder-Decoder Architectures with Attention
Convolution
sliding a small filter over an image (or signal) and computing a weighted sum at each position. from The Convolution Operation
Cosine decay
smoothly decreasing the learning rate following a cosine curve. from Learning Rate Schedules and Warmup
Data augmentation
generating new training examples by applying label-preserving transformations to existing ones. from Data Augmentation
Data leakage
information about the target leaking into the training inputs in a way that inflates apparent performance unrealistically. from Debugging a Training Run
Data parallelism
splitting a batch across multiple workers, each computing gradients on its own shard. from Distributed and Data-Parallel Training
Data structure (for architecture choice)
whether the input is grid-shaped, sequential, graph-shaped, or none of these. from Choosing an Architecture for a Problem
Dead unit
a ReLU unit whose input is always negative, so it never activates or updates. from The Artificial Neuron and Activation Functions
Decoder
the RNN that generates the output sequence, starting from the context vector. from Sequence-to-Sequence Models
Degradation problem
very deep plain networks training worse, even on training data, as depth increases past a point. from Residual and Skip Connections
Depth
the number of layers in a network. from The Multilayer Feedforward Network
Dequantization
converting a quantized integer code back into its approximate real value. from Quantization
Design walkthrough
working through a project's decisions in the order they naturally arise, each backed by evidence. from Capstone: Designing a Deep Learning System End to End
Differential privacy
training techniques that limit how much any single training example can be inferred from a trained model. from Ethics and Safety of Deep Systems
Dilated convolution
a filter variant that grows the receptive field by spacing out its taps, without adding layers or downsampling. from Receptive Fields and Depth
Diminishing returns
a shrinking relative improvement from each further increase in scale. from Scaling Laws and Model Capacity
Discriminator
the network trained to distinguish real samples from the generator's fakes. from Generative Adversarial Networks
Distillation loss
cross-entropy between a student's and teacher's softened output distributions. from Knowledge Distillation
Double descent
test error falling, rising to a peak at the interpolation threshold, then falling again with further capacity. from Overfitting and Double Descent
Downstream task
the real task of interest, which reuses representations learned via a pretext task. from Self-Supervised Learning
Drop probability (p)
the chance any given unit is zeroed on a given step. from Dropout
Dropout
randomly zeroing a fraction of a layer's units during training. from Dropout
Early stopping
halting training (or keeping an earlier checkpoint) once validation performance stops improving. from Early Stopping and Ensembling Deep Nets
Edge deployment
running a model directly on the end-user's device rather than a remote server. from Edge and On-Device Deep Learning
Encoder
the RNN that reads the input sequence and produces a context vector. from Sequence-to-Sequence Models
Encoder / decoder
the two halves of an autoencoder, compressing and then expanding the representation. from Autoencoders
End-to-end
covering a project from initial architecture choice through to a deployable, checked result. from Capstone: Designing a Deep Learning System End to End
Ensembling
averaging the predictions of several independently trained models. from Early Stopping and Ensembling Deep Nets
Epoch-units
a simple measure of total training compute used, summed across every candidate and training round. from Hyperparameter Tuning for Deep Networks
Euler's method
the simplest way to numerically solve a differential equation, taking fixed-size steps along the rate of change. from Neural ODEs
Expert
one of several separate sub-networks in a mixture-of-experts layer. from Mixture of Experts
Exploding gradient
a gradient that grows without bound as it propagates back through many layers. from Vanishing and Exploding Gradients
Exponential separation
when one architecture needs exponentially more units than another to represent the same function. from Why Depth Helps
Fan-in
the number of inputs feeding into a given unit. from Weight Initialization
Feature extraction (as a transfer strategy)
freezing a pretrained backbone and training only a new output layer. from Transfer Learning and Fine-Tuning
Feature hierarchy
the tendency for depth to progress from simple, generic features to complex, task-specific ones. from What Deep Networks Learn
Feature map
the 2D grid of outputs produced by sliding one filter over an input. from Filters, Feature Maps and Channels
FGSM (Fast Gradient Sign Method)
a simple adversarial attack using the sign of the gradient to perturb every input dimension by a fixed small step. from Adversarial Examples and Robustness
Filter depth
the number of 2D grids making up one filter, equal to its input's channel count. from Filters, Feature Maps and Channels
Filter visualization
directly viewing a layer's filter weights as image patches, most interpretable at the first layer. from Feature Visualization
Fine-tuning
continuing to train some or all of a pretrained model's own weights on a new task. from Transfer Learning and Fine-Tuning
Flatten
reshaping a feature map into a single vector, with no computation. from Image Classification End to End
Forget, input, output gates
learned sigmoid layers controlling what is kept, added, and revealed at each step. from Long Short-Term Memory
Forward (noising) process
the fixed, un-learned process of gradually adding noise to data. from Diffusion Models
Forward pass
computing a network's output from its input, layer by layer. from The Multilayer Feedforward Network
Frequency (in positional encoding)
how quickly a given dimension's value changes from one position to the next. from Positional Encoding
Fully connected (dense) layer
a layer connecting every input to every output with its own weight. from From Linear Models to Neural Networks
Generative misuse
using a generative model's realistic output to deceive or defraud. from Ethics and Safety of Deep Systems
Generator
the network that turns random noise into fake samples. from Generative Adversarial Networks
Generic vs. task-specific features
reusable low-level patterns versus patterns specialised to one particular task. from What Deep Networks Learn
GloVe
an alternative method learning embeddings directly from word co-occurrence statistics. from Word Embeddings
GPU (graphics processing unit)
hardware with many simple cores, well-suited to the kind of massive, uniform parallelism matrix multiplication needs. from Why GPUs and Accelerators
Gradient clipping
capping the size of a gradient before using it in an update. from Gradient Clipping
Gradient noise
the random variation of a batch gradient around the true, full-dataset gradient. from Batch Size and Training Dynamics
Gradient norm
the size (magnitude) of the overall gradient vector at a given training step, often monitored to catch instability early. from Debugging a Training Run
Graph neural network (GNN)
a network whose layers aggregate information from each node's actual graph neighbours. from Graph Neural Networks
He initialization
a variant scaled for ReLU networks. from Weight Initialization
Head dimension
the (usually reduced) dimensionality each head's projections operate in. from Multi-Head Attention
Hidden layer
a layer of units between the input and the output, not observed directly. from From Linear Models to Neural Networks
Hidden state
the vector an RNN carries from one time step to the next, summarising everything seen so far. from Recurrent Neural Networks
Hop
one edge's worth of distance in a graph; a GNN with k layers can reach information up to k hops away. from Graph Neural Networks
Hyperband
a practical algorithm running several successive-halving schedules in parallel to hedge against early elimination risk. from Hyperparameter Tuning for Deep Networks
Ill-conditioned loss
a loss surface with very different curvatures in different directions. from Second-Order and Natural Gradient Ideas
ImageNet
the large-scale image classification benchmark these architectures competed on. from CNN Architectures: From LeNet to ResNet
InfoNCE loss
the standard contrastive loss, a softmax cross-entropy over similarity scores against one true positive. from Contrastive Learning
Integrated gradients
an attribution method that averages the gradient along a path from a baseline input to the actual input. from Interpretability and Attribution
Interpolation threshold
the point where a model has just enough capacity to fit its training data exactly. from Overfitting and Double Descent
Intersection over Union (IoU)
the overlap area between two boxes divided by their combined (union) area. from Object Detection and Segmentation
Invariance
a property of the task (like orientation not mattering for "is this a cat") that augmentation teaches the network to respect. from Data Augmentation
Inverted dropout
scaling surviving units up by 1/(1 − p) so the expected activation is unchanged. from Dropout
Jacobian determinant
the local stretching (or shrinking) factor a transformation applies to volume (or, in 1D, length). from Normalizing Flows
Jump (cumulative stride)
the product of all strides applied so far, which scales how fast later layers grow the receptive field. from Receptive Fields and Depth
Kernel (filter)
the small grid of learned (or hand-designed) weights being slid across the input. from The Convolution Operation
KL divergence
a measure of how different two probability distributions are, used here to pull latent distributions toward the standard normal. from Variational Autoencoders
Label-preserving transformation
a change to the input that does not change the correct output. from Data Augmentation
Law of large numbers
the statistical fact that averaging more samples reduces estimation noise. from Batch Size and Training Dynamics
Layer normalization
normalizing across one example's own features, independent of the batch. from Layer Normalization
Learning rate schedule
a rule for changing the learning rate over the course of training. from Learning Rate Schedules and Warmup
LeNet, AlexNet, VGGNet, ResNet
four landmark CNN architectures, each solving a bottleneck of the one before it. from CNN Architectures: From LeNet to ResNet
Linearly separable
classes a single straight line (or hyperplane) can divide. from From Linear Models to Neural Networks
Logits
the raw, pre-softmax scores produced by the final dense layer. from Image Classification End to End
Loss curve
the plot of training (and validation) loss over time, the first and most informative diagnostic tool for a training run. from Debugging a Training Run
Loss scaling
multiplying the loss by a large constant to prevent small gradients from underflowing in low precision. from Mixed Precision Training
Magnitude pruning
removing the smallest-magnitude weights specifically. from Model Pruning
Membership inference attack
inferring whether a specific record was in a model's training data. from Ethics and Safety of Deep Systems
Message passing
the aggregate-then-update pattern a GNN layer performs. from Graph Neural Networks
Minimum-norm solution
among all parameter settings that fit the training data exactly, the one with the smallest overall size. from Overfitting and Double Descent
Mixed precision training
running most computation in a lower-precision format while keeping precision-sensitive parts at higher precision. from Mixed Precision Training
Modality
a kind of data (vision, audio, language, and others), each with its own typical raw representation. from Deep Learning Across Modalities
Mode collapse
a generator producing a narrow range of outputs rather than diverse ones. from Training Instabilities in GANs
Multi-head attention
running several attention heads in parallel and concatenating their outputs. from Multi-Head Attention
Multimodal
a problem combining more than one kind of data structure (such as images and text together). from Choosing an Architecture for a Problem
Multimodal model
a model that combines information from more than one modality. from Deep Learning Across Modalities
Negative sampling
approximating the full softmax by scoring the true context word against a small set of random negative examples. from Word Embeddings
Neural ODE
a network whose depth is treated as continuous time, with the hidden state's evolution defined by a differential equation. from Neural ODEs
Newton's method
the second-order update Δx = −H⁻¹g, exact in one step for a quadratic loss. from Second-Order and Natural Gradient Ideas
Noise schedule
the sequence of per-step noise amounts (β_t) controlling how quickly data is noised. from Diffusion Models
Non-linearity (activation function)
a function applied after each linear map that lets stacking add power. from From Linear Models to Neural Networks
Non-saturating loss
a generator loss formulation chosen specifically to avoid that vanishing-gradient trap. from Training Instabilities in GANs
Normalizing flow
a generative model built from invertible transformations with computable Jacobians. from Normalizing Flows
On-device inference
inference computed locally, with no network round trip. from Edge and On-Device Deep Learning
Padding
adding a border (usually zeros) around an input so a filter can reach its edges. from Padding, Stride and Pooling
Parallel processing
performing many independent operations at the same time rather than one after another. from Why GPUs and Accelerators
Parallelizable
able to be computed all at once rather than step by step. from Why Attention Replaced Recurrence
Path length
the number of sequential computation steps separating two positions in a sequence. from Why Attention Replaced Recurrence
Patience
the number of epochs without improvement tolerated before actually stopping. from Early Stopping and Ensembling Deep Nets
Permutation-invariant
unaffected by reordering the inputs — the property plain attention has without positional information. from Positional Encoding
Pipeline (convolve, pool, repeat, flatten, classify)
the standard structure of a CNN image classifier. from Image Classification End to End
Pooling
summarising each small patch of a feature map with one number (commonly the maximum or average), with no learned weights. from Padding, Stride and Pooling
Positional encoding
a position-dependent vector added to each token's embedding so order-sensitive information survives into attention. from Positional Encoding
Power law
a relationship where one quantity scales as a fixed power of another, appearing as a straight line on a log-log plot. from Scaling Laws and Model Capacity
Pre-deployment safety review
checking a model's privacy, robustness and fairness properties before it ships, not only its accuracy. from Capstone: Designing a Deep Learning System End to End
Pretext task
the specific, auto-labelled task a self-supervised model is trained to solve. from Self-Supervised Learning
Pruning
removing weights (or whole units) from a trained network to shrink it. from Model Pruning
Quadratic cost
compute or memory that grows with the square of the sequence length, as full self-attention's scoring does. from Why Attention Replaced Recurrence
Quantization
representing values with a smaller, fixed set of discrete levels instead of full floating-point precision. from Quantization
Receptive field
the region of the original input that a given unit's output depends on. from Receptive Fields and Depth
Reconstruction error
the difference between an autoencoder's input and its reconstructed output. from Autoencoders
Recurrence
reusing the same weights at every time step of a sequence. from Recurrent Neural Networks
ReLU
max(0, z), the most common hidden-layer activation in deep networks. from The Artificial Neuron and Activation Functions
Reparameterization trick
expressing a random sample as a differentiable function of learned parameters and independent noise. from Variational Autoencoders
Representational power
what a model family can express, independent of whether training finds it. from Universal Approximation
Reproducibility
the ability to obtain the same training result given the same starting conditions. from Checkpointing and Reproducibility
Reset gate
the gate controlling how much of the previous hidden state feeds into the new candidate's computation. from Gated Recurrent Units
Residual block
a block computing F(x) + x rather than just F(x). from Residual and Skip Connections
Reverse (denoising) process
the trained process of removing noise step by step, used to generate new samples. from Diffusion Models
Robustness
a model's resistance to deliberately adversarial (as opposed to naturally occurring) input changes. from Adversarial Examples and Robustness
Router (gating network)
the small network that scores and selects which experts handle a given input. from Mixture of Experts
Running statistics
the accumulated mean and variance used at test time instead of a single batch's. from Batch Normalization
Saliency map
a per-pixel measure of how sensitive a prediction is to small changes in that pixel. from Feature Visualization
Saturating gradient
a gradient that shrinks toward zero in exactly the situation where a strong training signal is most needed. from Training Instabilities in GANs
Saturation
a region of an activation function where its slope is close to zero. from The Artificial Neuron and Activation Functions
Scale
the spacing between adjacent quantization levels, determined by the value range and bit-width. from Quantization
Scaling law (in deep learning)
an empirical power-law relationship between a model's loss and its scale (parameters, data, or compute). from Scaling Laws and Model Capacity
Search space
the set of architecture choices a NAS method considers. from Neural Architecture Search
Search strategy
the method used to propose and evaluate candidate architectures. from Neural Architecture Search
Second-order method
an optimization method that uses curvature (second-derivative) information, not just the gradient. from Second-Order and Natural Gradient Ideas
Segmentation
labelling every pixel of an image, rather than the image as a whole. from Object Detection and Segmentation
Self-supervised learning
training with targets generated automatically from unlabelled data, rather than from human annotation. from Self-Supervised Learning
Skip connection
a path that carries a layer's input forward, around (added to) that layer's own output. from Residual and Skip Connections
Soft step
a scaled, shifted sigmoid used as a building block for approximating curves. from Universal Approximation
Sparsity
the fraction of a network's weights that have been pruned (set to zero). from Model Pruning
Stacked RNN
multiple RNN layers, each one's output sequence feeding the next as its input sequence. from Bidirectional and Stacked RNNs
Step decay
multiplying the learning rate by a fixed factor at set intervals. from Learning Rate Schedules and Warmup
Stride
the step size a filter moves between positions. from Padding, Stride and Pooling
Successive halving
a search strategy that eliminates the weaker half of candidates at each checkpoint, giving only survivors further training budget. from Hyperparameter Tuning for Deep Networks
Teacher / student
the large, already-trained model and the smaller model being trained to mimic it. from Knowledge Distillation
Teacher forcing
feeding the true previous output during training instead of the model's own generated output. from Sequence-to-Sequence Models
Temperature
a scaling factor that softens (or sharpens) a softmax distribution. from Knowledge Distillation
Temperature (τ)
a scaling constant controlling how sharply the softmax concentrates on the closest candidate. from Contrastive Learning
Top-k selection
keeping only the k highest-scoring experts and renormalising their weights. from Mixture of Experts
Train/test mismatch
the need for running statistics at test time that batch norm has and layer norm avoids. from Layer Normalization
Transfer learning
reusing a model trained on one task as the starting point for another. from Transfer Learning and Fine-Tuning
Truncated BPTT
backpropagating through only a limited number of recent steps instead of the whole sequence. from Backpropagation Through Time
Underflow
a value too small to represent in a given numerical format, rounding to zero. from Mixed Precision Training
Universal approximation theorem
a sufficiently wide one-hidden-layer network can approximate any continuous function on a bounded input. from Universal Approximation
Unrolling
representing a recurrence over T steps as an explicit T-layer computational graph. from Backpropagation Through Time
Update gate
the single gate controlling the trade-off between the old hidden state and the new candidate. from Gated Recurrent Units
Valid convolution
convolution with no padding, producing a smaller output than the input. from The Convolution Operation
Vanishing gradient
a gradient that shrinks toward zero as it propagates back through many layers. from Vanishing and Exploding Gradients
Variational autoencoder (VAE)
an autoencoder whose bottleneck is a learned probability distribution rather than a fixed vector. from Variational Autoencoders
Vision transformer
an architecture applying attention to image patches, adapting an idea originally developed for language. from Deep Learning Across Modalities
Warmup
a short initial phase that ramps the learning rate up from near zero. from Learning Rate Schedules and Warmup
Weight initialization
the rule for picking a network's starting weights. from Weight Initialization
Weight matrix
a layer's weights, one row per unit, one column per input. from The Multilayer Feedforward Network
Weight sharing across time
the same principle as a convolution's weight sharing across space, applied to sequence position instead. from Recurrent Neural Networks
Width
the number of units in a given layer. from The Multilayer Feedforward Network
word2vec
a family of methods (including skip-gram) that learn word embeddings by predicting context words. from Word Embeddings
Xavier (Glorot) initialization
scaling weights by roughly 1/√(fan-in). from Weight Initialization
γ, β
the learned per-unit scale and shift applied after normalization. from Batch Normalization
