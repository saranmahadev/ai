Deep Learning1 min read

The last section is judgment: picking an architecture, trusting it, knowing where it breaks, and seeing the whole subject in one project.

Topics in this section:

  • Choosing an Architecture for a Problem: matching a problem's data and constraints to a family of networks.
  • Adversarial Examples and Robustness: tiny, deliberate changes that fool a network that otherwise performs well.
  • Interpretability and Attribution: methods built for deep nets specifically to see which inputs drove a prediction.
  • Scaling Laws and Model Capacity: how performance moves as data, parameters and compute all grow together.
  • Deep Learning Across Modalities: the same architectural ideas at work in vision, speech and language.
  • Ethics and Safety of Deep Systems: risks that are specific to large, learned, hard-to-inspect models.
  • Capstone: Designing a Deep Learning System End to End: choosing, training, regularising and shipping one model for a real task.
