Neural Network Foundations

Deep Learning1 min read

A neural network is many simple units arranged in layers, each one a tiny scoring function like the ones on the Math and Machine Learning planets. This district builds that picture up from a single unit to a stack of them, and asks why stacking helps at all.

Topics on this stretch of the road:

  • From Linear Models to Neural Networks: what changes when you stack linear units instead of using just one.
  • The Artificial Neuron and Activation Functions: the unit itself, and why it needs a non-linear kink.
  • The Multilayer Feedforward Network: wiring neurons into layers and reading the forward pass.
  • Universal Approximation: how wide or deep a network needs to be to approximate (almost) any function.
  • Why Depth Helps: why stacking layers beats making one layer wider.

From Linear Models to Neural Networks

A single linear unit — a perceptron or a logistic regression — can only cut its input space with one straight line (or flat plane).

The Artificial Neuron and Activation Functions

An artificial neuron is a dot product plus a bias, passed through a non-linear activation function: a = f(w · x + b).

The Multilayer Feedforward Network

A multilayer feedforward network wires several artificial neurons into layers and runs them in one direction only, input to output, with no loops.

Deep Learning

Deep learning is machine learning with many-layered neural networks: instead of hand-picking features, you stack simple units into layers and let training discover the representations itself.
