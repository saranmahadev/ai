Sets, Logic and Counting

Math1 min read

This section covers the discrete foundations: collections of things (sets), statements that are true or false (logic), how to argue carefully (proofs), how to count possibilities, how to describe connections (graphs and trees), and how fast a computation grows. Probability is built on sets and counting, and every algorithm's cost is described by growth rates.

Topics in this section:

  • Sets and Operations: collections, unions, intersections and complements.
  • Logic and Truth Tables: AND, OR, NOT and IF-THEN.
  • Reading Proofs and Quantifiers: "for all", "there exists" and how arguments are built.
  • Counting Rules: multiplying and adding possibilities.
  • Permutations and Combinations: arrangements, selections and binomial coefficients.
  • Graphs and Networks: nodes and edges.
  • Trees and Hierarchies: graphs with no loops, and the decisions they encode.
  • Growth Rates and Big-O: how cost grows with size.

Sets and Operations

A set is a collection of distinct things, and a few operations (union, intersection, difference, complement) combine sets.

Logic and Truth Tables

Logic deals with statements that are either true or false and the ways of combining them: AND, OR, NOT, XOR and IF … THEN.

Reading Proofs and Quantifiers

A proof is an argument that a statement is true in every case, built from clear steps. Quantifiers ("for all", "there exists") say how many cases a statement covers.

Counting Rules

Counting answers "how many ways can this happen?" without listing them all.

Permutations and Combinations

A permutation counts arrangements where order matters, and a combination counts selections where order does not matter.

Graphs and Networks

A graph is a set of nodes joined by edges. It is the natural way to describe anything connected: friends, roads, web pages, atoms, and the computation inside a neural network.
