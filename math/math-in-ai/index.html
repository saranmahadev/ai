Math in AI

Math1 min read

This last district puts the earlier ones to work. Each topic takes a real piece of machine learning, from a straight-line fit to the attention layer of a Transformer, and computes it by hand with small numbers, naming the maths from the road behind you at every step. If you can follow these, you can read the equations in most machine-learning papers.

Topics on this stretch of the road:

  • Linear Regression End to End: fitting a line by formula and by gradient descent.
  • Logistic Regression and the Sigmoid: turning a score into a probability for yes/no questions.
  • A Forward Pass by Hand: a tiny neural network computed step by step.
  • Backpropagation by Hand: the same network's gradients, and one learning step.
  • Softmax and Cross-Entropy in Practice: many-class probabilities and their loss.
  • Embeddings and Similarity Search: meaning as vectors, and finding neighbours.
  • Attention as Dot Products: the core of the Transformer, in three lines.
  • Bias, Variance and the Whole Picture: why models err, and how the pieces fit together.

From here the road leads to Machine Learning and beyond, where these calculations are done at scale.

Linear Regression End to End

Linear regression fits a straight line ŷ = m·x + b to data by choosing the slope and intercept that minimise the mean squared error.

Logistic Regression and the Sigmoid

Logistic regression answers yes/no questions with a probability.

A Forward Pass by Hand

A forward pass pushes an input through a network layer by layer to produce a prediction. Each layer is the same recipe: multiply by a weight matrix, add a bias, apply an activation function.

Backpropagation by Hand

Backpropagation computes how the loss changes with every weight in a network by applying the chain rule backwards from the output. Its results are exactly the gradients that gradient descent needs.

Softmax and Cross-Entropy in Practice

For questions with many possible answers, a network outputs one raw score (a logit) per class.

Embeddings and Similarity Search

An embedding represents a word, image, song or user as a vector of numbers, learned so that similar things end up close together.
