Everything on this road so far has covered one piece of an agent at a time. This last district is about running the whole thing: seeing what an agent actually did across a long run, what it costs to keep it running, and a capstone that traces one goal through every stage this planet covered.

Topics on this stretch of the road:

* [[Observability and Tracing for Agent Runs]]: recording every step, tool call and decision an agent made, so a run can actually be debugged after the fact.
* [[Production Agent Architecture]]: how the pieces on this road fit into one running system.
* [[Cost and Latency of Agent Loops]]: why an agent's total cost and time can run far past a single LLM call's, and where that actually accumulates.
* [[Capstone: A Goal, Decomposed, Executed and Verified End to End]]: one goal, through planning, tool use, memory, reflection and verification, end to end.
