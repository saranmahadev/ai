A

Absolute inhibition
an inhibitory input that, if active, forces the output to 0 regardless of any excitatory input.
The McCulloch-Pitts Neuron
Asynchronous update
updating one unit at a time, using the current states of all the others.
Hopfield Networks
Attractor
a stable state that nearby states settle into; here, a local minimum of the energy function.
Energy Functions and Attractor Dynamics

B

Best-matching unit (BMU)
the grid unit whose weight vector is closest to the current input.
Self-Organizing Maps
Bipartite connectivity
connections only between two groups of units (visible and hidden), none within either group.
Restricted Boltzmann Machines
Bottleneck
the smallest layer of an autoencoder, forcing it to compress rather than copy its input.
Stacked Autoencoders Before End-to-End Training

C

Capacity
the largest number of patterns a memory network can store while still reliably recalling each one.
Content-Addressable Memory and Capacity
Capacity (recall)
the pattern-storage limit of a Hopfield network, from Content-Addressable Memory and Capacity.
Choosing Classical vs Modern Approaches
Causal (pre-before-post) window
the time range where the presynaptic spike precedes the postsynaptic one, where STDP strengthens the connection.
Spike-Timing-Dependent Plasticity
Centre
the fixed point in input space an RBF unit measures distance from.
Radial Basis Function Networks
Closed-form solution
a solution obtained by direct computation (here, linear least squares), rather than iterative optimization.
Radial Basis Function Networks
Code
the compressed, encoder-only output of a trained autoencoder, used as the next layer's input.

Codebook vector (prototype)
one of a fixed set of representative vectors, each claiming the inputs nearest to it.
Competitive Learning and Vector Quantization
Constraint-matched choice
selecting a method based on which specific assumption of standard deep learning the problem violates, not on raw model capacity.
Choosing Classical vs Modern Approaches
Content-addressable memory
retrieving a stored item by giving part or a noisy version of it, rather than an index.
Hopfield Networks
Continuous (modern) Hopfield network
a generalization of the classical network to continuous states, whose update rule is mathematically equivalent to attention.
Modern Hopfield Networks and Attention
Contrastive divergence
an approximate training rule comparing data-driven correlations against the model's own short reconstruction.
Restricted Boltzmann Machines
Correlation-driven learning
adjusting weights based on how often two neurons are active together, with no target.

D

Deep belief network
a stack of RBMs trained this way, each one's hidden layer feeding the next as data.
Deep Belief Networks
Dendrite, soma, axon, synapse
the parts of a real neuron that receive, integrate, transmit, and connect to the next neuron.
The Biological Neuron
Duty cycle
how often a system is actually active, used here as a stand-in for a spiking network's firing rate.

E

Energy function
a single number computed from a Hopfield network's current state, built so stored patterns sit at low values.
Energy Functions and Attractor Dynamics
Energy-driven settling
a network moving toward lower-energy states instead of following a gradient of error.
Why This Planet Looks Different from Deep Learning
Error-driven learning
adjusting weights to reduce a measured difference from a known target.
Why This Planet Looks Different from Deep Learning
Event-driven computation
performing work only in response to an actual event (here, a spike), rather than on every tick of a global clock.
Neuromorphic Hardware
Excitatory / inhibitory connection
a connection that votes toward firing, or that can veto firing outright.
The McCulloch-Pitts Neuron
Extreme learning machine (ELM)
a single-hidden-layer network with random, untrained hidden weights and a least-squares-solved output layer.
Extreme Learning Machines

F

Fine-tuning
an optional final stage adjusting the whole, already-pretrained stack together, typically with labelled data and backpropagation.
Deep Belief Networks
Firing rate
the number of spikes a neuron produces per unit time, one simplified summary of its activity.
The Biological Neuron
the spike count in a window divided by the window's length.
Rate and Temporal Coding

G

Gibbs sampling
repeatedly sampling each unit's state from its conditional probability given all the others, holding the rest fixed.
Boltzmann Machines
Greedy layer-wise training
training one layer fully before introducing the next, never revisiting earlier layers.
Deep Belief Networks

H

Hebbian learning
strengthening a connection in proportion to how often the two neurons it connects are active together.
Hebbian Learning

I

Inverse temperature (β)
a parameter sharpening or softening the softmax weighting over stored patterns, playing the same role as attention's scaling factor.
Modern Hopfield Networks and Attention

L

Leaky integrate-and-fire (LIF)
a spiking neuron model that accumulates input, leaks a fraction away each step, and fires when a threshold is crossed.
Spiking Neural Networks
Learning window
the shape of weight change as a function of the time gap between two spikes, typically peaked near zero and decaying exponentially.
Spike-Timing-Dependent Plasticity
Local field
the weighted sum a unit's own update rule uses, h_i = Σⱼ W_ij s_j.
Energy Functions and Attractor Dynamics

M

McCulloch-Pitts (MCP) neuron
the first mathematical neuron model (1943), with binary inputs, hand-set excitatory/inhibitory weights, and no learning rule.
The McCulloch-Pitts Neuron
Mean squared error (MSE)
the average squared difference between predictions and targets, used here to measure fit quality.
Extreme Learning Machines
Membrane potential
the accumulated value a spiking neuron tracks over time, analogous to a real neuron's voltage.
Spiking Neural Networks

N

Negative phase
the part of the gradient that should reflect the model's own equilibrium distribution, approximated by a short Gibbs chain in CD-k.
Contrastive Divergence
Neighbourhood function
a function of grid distance from the BMU that scales how much each unit is updated.
Self-Organizing Maps
Neuromorphic chip
hardware built to run spiking neurons' event-driven dynamics directly, rather than simulating them step by step on a conventional processor.
Neuromorphic Hardware

P

Persistent contrastive divergence
a variant that keeps a Gibbs chain running across updates instead of restarting it at the data each time.
Contrastive Divergence
Phase transition
a sharp, not gradual, change in behaviour as a parameter (here, patterns per unit) crosses a threshold.

Positive phase
the part of the gradient computed from real data.

Presynaptic / postsynaptic
the input-side and output-side neuron of a connection.

the sending neuron and the receiving neuron of a given connection, respectively.

Q

Query, key, value

R

Random feature
a fixed, randomly-parameterized nonlinear function used as one "column" of the hidden representation.

Rate coding
representing information as a firing rate rather than exact spike timing.
The Biological Neuron
representing a signal's strength by how many spikes occur in a fixed time window.

Readout

Reconstruction

Reconstruction error

Reservoir

Simulated annealing

Sparsity advantage

Spurious state

Stable point (attractor)
a state the update rule leaves unchanged; a stored pattern is designed to be one.
