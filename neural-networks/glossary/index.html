Neural Networks Glossary

68 terms from Neural Networks.

Absolute inhibition
an inhibitory input that, if active, forces the output to 0 regardless of any excitatory input. from The McCulloch-Pitts Neuron
Asynchronous update
updating one unit at a time, using the current states of all the others. from Hopfield Networks
Attractor
a stable state that nearby states settle into; here, a local minimum of the energy function. from Energy Functions and Attractor Dynamics
Best-matching unit (BMU)
the grid unit whose weight vector is closest to the current input. from Self-Organizing Maps
Bipartite connectivity
connections only between two groups of units (visible and hidden), none within either group. from Restricted Boltzmann Machines
Bottleneck
the smallest layer of an autoencoder, forcing it to compress rather than copy its input. from Stacked Autoencoders Before End-to-End Training
Capacity
the largest number of patterns a memory network can store while still reliably recalling each one. from Content-Addressable Memory and Capacity
Capacity (recall)
the pattern-storage limit of a Hopfield network, from Content-Addressable Memory and Capacity. from Choosing Classical vs Modern Approaches
Causal (pre-before-post) window
the time range where the presynaptic spike precedes the postsynaptic one, where STDP strengthens the connection. from Spike-Timing-Dependent Plasticity
Centre
the fixed point in input space an RBF unit measures distance from. from Radial Basis Function Networks
Closed-form solution
a solution obtained by direct computation (here, linear least squares), rather than iterative optimization. from Radial Basis Function Networks
Code
the compressed, encoder-only output of a trained autoencoder, used as the next layer's input. from Stacked Autoencoders Before End-to-End Training
Codebook vector (prototype)
one of a fixed set of representative vectors, each claiming the inputs nearest to it. from Competitive Learning and Vector Quantization
Constraint-matched choice
selecting a method based on which specific assumption of standard deep learning the problem violates, not on raw model capacity. from Choosing Classical vs Modern Approaches
Content-addressable memory
retrieving a stored item by giving part or a noisy version of it, rather than an index. from Hopfield Networks
Continuous (modern) Hopfield network
a generalization of the classical network to continuous states, whose update rule is mathematically equivalent to attention. from Modern Hopfield Networks and Attention
Contrastive divergence
an approximate training rule comparing data-driven correlations against the model's own short reconstruction. from Restricted Boltzmann Machines
Correlation-driven learning
adjusting weights based on how often two neurons are active together, with no target. from Why This Planet Looks Different from Deep Learning
Deep belief network
a stack of RBMs trained this way, each one's hidden layer feeding the next as data. from Deep Belief Networks
Dendrite, soma, axon, synapse
the parts of a real neuron that receive, integrate, transmit, and connect to the next neuron. from The Biological Neuron
Duty cycle
how often a system is actually active, used here as a stand-in for a spiking network's firing rate. from Capstone: Where Classical Neural Computing Meets Modern Deep Learning
Energy function
a single number computed from a Hopfield network's current state, built so stored patterns sit at low values. from Energy Functions and Attractor Dynamics
Energy-driven settling
a network moving toward lower-energy states instead of following a gradient of error. from Why This Planet Looks Different from Deep Learning
Error-driven learning
adjusting weights to reduce a measured difference from a known target. from Why This Planet Looks Different from Deep Learning
Event-driven computation
performing work only in response to an actual event (here, a spike), rather than on every tick of a global clock. from Neuromorphic Hardware
Excitatory / inhibitory connection
a connection that votes toward firing, or that can veto firing outright. from The McCulloch-Pitts Neuron
Extreme learning machine (ELM)
a single-hidden-layer network with random, untrained hidden weights and a least-squares-solved output layer. from Extreme Learning Machines
Fine-tuning
an optional final stage adjusting the whole, already-pretrained stack together, typically with labelled data and backpropagation. from Deep Belief Networks
Firing rate
the number of spikes a neuron produces per unit time, one simplified summary of its activity. from The Biological Neuron
the spike count in a window divided by the window's length. from Rate and Temporal Coding
Gibbs sampling
repeatedly sampling each unit's state from its conditional probability given all the others, holding the rest fixed. from Boltzmann Machines
Greedy layer-wise training
training one layer fully before introducing the next, never revisiting earlier layers. from Deep Belief Networks
Hebbian learning
strengthening a connection in proportion to how often the two neurons it connects are active together. from Hebbian Learning
Inverse temperature (β)
a parameter sharpening or softening the softmax weighting over stored patterns, playing the same role as attention's scaling factor. from Modern Hopfield Networks and Attention
Leaky integrate-and-fire (LIF)
a spiking neuron model that accumulates input, leaks a fraction away each step, and fires when a threshold is crossed. from Spiking Neural Networks
Learning window
the shape of weight change as a function of the time gap between two spikes, typically peaked near zero and decaying exponentially. from Spike-Timing-Dependent Plasticity
Local field
the weighted sum a unit's own update rule uses, h_i = Σⱼ W_ij s_j. from Energy Functions and Attractor Dynamics
McCulloch-Pitts (MCP) neuron
the first mathematical neuron model (1943), with binary inputs, hand-set excitatory/inhibitory weights, and no learning rule. from The McCulloch-Pitts Neuron
Mean squared error (MSE)
the average squared difference between predictions and targets, used here to measure fit quality. from Extreme Learning Machines
Membrane potential
the accumulated value a spiking neuron tracks over time, analogous to a real neuron's voltage. from Spiking Neural Networks
Negative phase
the part of the gradient that should reflect the model's own equilibrium distribution, approximated by a short Gibbs chain in CD-k. from Contrastive Divergence
Neighbourhood function
a function of grid distance from the BMU that scales how much each unit is updated. from Self-Organizing Maps
Neuromorphic chip
hardware built to run spiking neurons' event-driven dynamics directly, rather than simulating them step by step on a conventional processor. from Neuromorphic Hardware
Persistent contrastive divergence
a variant that keeps a Gibbs chain running across updates instead of restarting it at the data each time. from Contrastive Divergence
Phase transition
a sharp, not gradual, change in behaviour as a parameter (here, patterns per unit) crosses a threshold. from Content-Addressable Memory and Capacity
Positive phase
the part of the gradient computed from real data. from Contrastive Divergence
Presynaptic / postsynaptic
the input-side and output-side neuron of a connection. from Hebbian Learning
the sending neuron and the receiving neuron of a given connection, respectively. from Spike-Timing-Dependent Plasticity
Query, key, value
the roles the current state and the stored patterns play in the shared formula, using attention's standard vocabulary. from Modern Hopfield Networks and Attention
Random feature
a fixed, randomly-parameterized nonlinear function used as one "column" of the hidden representation. from Extreme Learning Machines
Rate coding
representing information as a firing rate rather than exact spike timing. from The Biological Neuron
representing a signal's strength by how many spikes occur in a fixed time window. from Rate and Temporal Coding
Readout
the trained linear layer mapping the reservoir's current state to the desired output. from Reservoir Computing and Liquid State Machines
Reconstruction
the visible-layer sample produced by running the hidden layer's sample back through the model. from Restricted Boltzmann Machines
Reconstruction error
the squared difference between an autoencoder's input and its decoded output, minimized during training. from Stacked Autoencoders Before End-to-End Training
Reservoir
a large, fixed, randomly-wired recurrent network whose dynamics are never trained. from Reservoir Computing and Liquid State Machines
Simulated annealing
cooling the temperature over the course of a run to combine early exploration with late-stage settling. from Boltzmann Machines
Sparsity advantage
the ratio of synchronous to event-driven computational cost, equal to the reciprocal of the firing rate. from Neuromorphic Hardware
the computational saving from event-driven hardware, from Neuromorphic Hardware. from Choosing Classical vs Modern Approaches
Spectral radius
the largest eigenvalue magnitude of the reservoir's recurrent weight matrix, kept below roughly 1 for stable dynamics. from Reservoir Computing and Liquid State Machines
Spike
a discrete, all-or-nothing firing event, followed by a reset of the membrane potential. from Spiking Neural Networks
Spurious state
a stable point of the energy landscape that is not one of the intended stored patterns, often created by interference between several. from Content-Addressable Memory and Capacity
Stable point (attractor)
a state the update rule leaves unchanged; a stored pattern is designed to be one. from Hopfield Networks
Temperature
a parameter controlling how stochastic a Boltzmann machine's updates are; low temperature behaves like a Hopfield network, high temperature behaves nearly randomly. from Boltzmann Machines
Temperature convergence
the continuous Hopfield update's weighting approaching the classical network's discrete answer as its inverse-temperature parameter β grows. from Capstone: Where Classical Neural Computing Meets Modern Deep Learning
Temporal (latency) coding
representing a signal's strength by the precise timing of spikes, often the delay to the first one. from Rate and Temporal Coding
Topological map
a layout where nearby positions on the grid correspond to similar regions of the input space. from Self-Organizing Maps
Unsupervised rule
a learning rule needing no labelled target to compare against. from Hebbian Learning
Vector quantization
representing data by the index of its nearest codebook vector. from Competitive Learning and Vector Quantization
Width (σ)
how quickly an RBF unit's response fades as the input moves away from its centre. from Radial Basis Function Networks
Winner-take-all
an update rule where only the single best-matching unit changes on each input. from Competitive Learning and Vector Quantization
Worked walkthrough
checking a general claim on one small, fully-verifiable example, rather than relying on the general argument alone. from Capstone: Where Classical Neural Computing Meets Modern Deep Learning
